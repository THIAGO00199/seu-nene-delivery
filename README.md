# Seu Nenê Delivery

Cardápio digital demonstrativo do Restaurante e Pizzaria Seu Nenê, em Jandaia do Sul (PR).

## Recursos
- 68 itens do cardápio organizados por categoria
- busca e favoritos persistentes
- seleção de tamanho e pizza de dois sabores
- carrinho persistente e modo entrega/retirada
- histórico local de pedidos demonstrativos
- layout responsivo para celular e desktop
- deploy automático no GitHub Pages

## Rodar localmente
```bash
npm install
npm run dev
```

## Aviso
Os preços e itens foram transcritos do cardápio público consultado em outubro de 2026. A aplicação é uma prévia: não processa cobrança e não envia pedidos automaticamente.
